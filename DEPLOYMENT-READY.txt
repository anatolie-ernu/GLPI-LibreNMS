1. COPY FILES TO YOUR SERVER
   cp -r /mnt/user-data/outputs/* /path/to/GLPI-LibreNMS/

2. RUN INSTALLER (Choose one):

   Option A - Interactive (RECOMMENDED):
   $ ./install.sh
   
   Option B - With parameters:
   $ ./configure.sh local glpi librenms npm admin@ernu.md Pass123!
   
   Option C - Manual:
   $ cp .env.example .env
   $ nano .env
   $ docker-compose up -d

3. CONFIGURE DNS LOCAL
   (Instructions shown by installer)

4. ACCESS SERVICES
   - http://npm.local:81/     (Admin)

5. INITIALIZE & CONFIGURE
   (Follow documentation)
